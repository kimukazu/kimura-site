# 意思決定の記録

## 2026-10-22 事業ブロック全体を外部サイトへのリンクにする方法

- 2026-10-31 に廃止。下の「カード全体のリンクの廃止」を参照。以下は当時の記録。
- 採用: JavaScript ではなく CSS の stretched link（文字リンクの ::after をブロック全体に広げる方法）。
- 理由: `<a>` の入れ子は HTML として不正。JavaScript が無効でも動く。キーボード操作で「公式サイト」「Instagram」の2つのリンクが別々に辿れる。
- トレードオフ: ブロック内の文字をマウスで選択できなくなる。
- 写真は `pointer-events: none` でクリック判定から外す。理由: ホバーで拡大（transform）した写真が `::after` より前面に描画され、クリックを奪うため。`::after` の z-index を上げるだけでは、リンクの opacity による重なり文脈に閉じ込められて効かない。
- ホバー効果は `@media (hover: hover)` に限定。理由: タッチ端末でタップ後に :hover が残り、拡大・半透明のままになるため。

## 2026-10-22 Instagram アイコンの入手方法

- 採用: Simple Icons（CC0）の SVG を `assets/img/icon-instagram.svg` として同梱。
- 理由: 無料・商用利用可、外部 CDN に依存しない。

## 2026-10-31 カード全体のリンクと「楽器購入ページ」リンクの分離

- 2026-10-31 に廃止。下の「カード全体のリンクの廃止」を参照。以下は当時の記録。
- 採用: カード全体(公式サイトトップ)と文字リンク(商品一覧ページ)を別の `<a>` にする。カード用は透明な `position: absolute; inset: 0` の `<a>` をブロック先頭に置く(グリッドの子だが absolute なので列・行に入らない)。Instagram・購入ページのリンクは `z-index: 1` で手前に出す。
- 理由: 飛び先が異なるため、1 本のリンクの `::after` を広げる従来の方法では表現できない。
- キーボード操作の順番: カード(公式サイト)→ Instagram → 楽器購入ページ。カードにフォーカスするとブロック全体に枠が出る。
- カードにホバーしても文字リンクは薄くしない。理由: カード(公式サイトトップ)と文字リンク(商品一覧)は飛び先が別で、同じ反応にすると同じリンクに見えるため。
- 文字リンクの書体は Noto Sans JP 700。理由: 表示文字が日本語になり、Inter(英字のみ)では OS の書体で表示されてしまうため。

## 2026-10-31 カード全体のリンクの廃止

- 採用: 事業ブロック全体のリンク(透明な `<a>`)をやめ、Instagram と「楽器購入ページ」の文字リンクだけを押せるようにする。Instagram はアイコンの右に「Instagram ↗」の文字を添え、アイコンと文字で 1 つのリンクにする。
- 理由: Kazuki の判断。スマホではカードの飛び先が画面に見えず、見出しをタップしただけで別サイトが開くのを避ける。写真のホバー拡大と `pointer-events: none` も不要になったので削除。
- 2 つの文字リンクは同じ見た目(Noto Sans JP 700、14px、下線、矢印 ↗)。タップしやすいよう各リンクの高さは 44px を確保。
- ホバー表示を `@media (hover: hover)` に限定する方針(10-22 の項)は引き続き採用(タッチ端末でタップ後に薄い表示が残らないようにするため)。
- リンクの読み上げ名は画面の文字で始める(例: 「Instagram（Nord Guitar Vault、新しいタブで開きます）」)。理由: 音声操作で画面の文字を言えば選べるようにするため(WCAG 2.5.3)。
