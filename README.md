# 木村インダストリー株式会社 コーポレートサイト

このフォルダには、会社ホームページのファイル一式が入っています。
特別なソフト（プログラムを組み立てる道具）は使っておらず、HTML・CSS・JavaScriptという
Webページの基本的な言語だけでできています。そのため、パソコンの中の「メモ帳」のような
テキスト編集ソフトでも文章を直すことができます。

## フォルダの中身

| ファイル・フォルダ | 内容 |
|---|---|
| `index.html` | トップページ |
| `contact.html` | お問い合わせページ |
| `css/style.css` | デザイン（色・文字の大きさ・余白など）をまとめたファイル |
| `js/main.js` | 動き（スクロールで文字がふわっと出る、フォーム送信など）をまとめたファイル |
| `assets/img/` | 写真ファイル |
| `assets/video/` | トップページ冒頭の動画ファイル |

## よくある更新方法

### 1. 文章を直したいとき

`index.html` または `contact.html` を、テキストエディタ（メモ帳、VS Codeなど）で開きます。
直したい日本語の文章を探して書き換え、保存するだけで反映されます。
（タグと呼ばれる `<p>...</p>` のような記号は消さずに、その内側の文字だけを書き換えてください。）

例：会社の住所を変える場合は、`index.html` と `contact.html` の中の
「〒095-0062　北海道士別市武徳町45線東3号」という文字列を探して書き換えてください。
（同じ住所が index.html 内に2箇所、contact.html 内に1箇所あります）

### 2. 写真を差し替えたいとき

`assets/img/` フォルダの中の画像（例：`service01.jpg`）と同じファイル名で、
新しい写真を上書き保存してください。ファイル名を変える場合は、
`index.html` の中で `src="assets/img/service01.jpg"` と書かれている箇所も
新しいファイル名に合わせて書き換える必要があります。

### 3. 電話番号・メールアドレスを変えたいとき

`contact.html` の中の以下の2箇所を書き換えてください。

- `tel:0165-22-0437` の部分（電話番号のリンク）
- `mailto:info@kimuraindustry.jp` の部分（メールのリンク、2箇所あります）

同時に画面に表示されている文字（`0165-22-0437` や `info@kimuraindustry.jp`）も
書き換えてください。

## パソコンで見た目を確認する方法

`index.html` のファイルを、ブラウザ（Google Chrome や Microsoft Edge など）に
ドラッグ＆ドロップするだけで、インターネットにつながなくても見た目を確認できます。

## 公開方法（GitHub Pages）

このサイトは GitHub Pages（GitHub社が無料で提供しているホームページ公開サービス）で
公開することを想定しています。すべてのファイルの中でリンクや画像のパスは
「相対パス」（フォルダの中の場所だけを示す書き方）になっているため、
GitHubのリポジトリにこのフォルダの中身をそのままアップロードし、
GitHub Pagesの設定を有効にするだけで公開できます。

1. GitHubでリポジトリを作成し、このフォルダの中身一式をアップロード（push）する
2. リポジトリの「Settings」→「Pages」で、公開するブランチ（例：`main`）を選択する
3. 数分後に発行されるURL（例：`https://ユーザー名.github.io/リポジトリ名/`）でサイトが見られるようになる

## 注意点

- 画像・動画ファイル（`assets/img/`、`assets/video/`）は容量が大きいため、
  差し替える際はできるだけ元のファイルサイズに近いものを使うと表示が重くなりません。
- スマートフォンで見たときのレイアウトも自動で調整されるようになっていますが、
  大きく文章量を増やす場合は、スマホ画面でも崩れていないか確認してください。
